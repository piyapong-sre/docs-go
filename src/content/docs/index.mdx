## สิ่งที่ต้องมีก่อนเริ่ม

- คอมพิวเตอร์ที่ติดตั้ง Go ได้ (Windows, macOS หรือ Linux)
- พื้นฐานการใช้ terminal เบื้องต้น
- ถ้าเคยเขียนภาษาอื่นมาก่อนจะเรียนได้เร็วขึ้น แต่ไม่จำเป็น
