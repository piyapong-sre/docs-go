operator ของ Go คล้ายกับภาษาตระกูล C (C, Java, JavaScript) แต่มีจุดที่ตั้งใจทำให้ **เรียบง่ายและปลอดภัยกว่า** เช่น ไม่มี ternary operator และ `++` เป็น statement ไม่ใช่ expression บทนี้จะรวบรวมทั้งหมดพร้อมจุดที่ต้องระวัง

## คณิตศาสตร์

| Operator | ความหมาย | ใช้กับ |
| --- | --- | --- |
| `+` | บวก / ต่อ string | ตัวเลข, string |
| `-` | ลบ | ตัวเลข |
| `*` | คูณ | ตัวเลข |
| `/` | หาร | ตัวเลข |
| `%` | เศษจากการหาร (remainder) | จำนวนเต็มเท่านั้น |

<Aside type="caution" title="int หาร int ได้ int">
`17 / 5` ได้ `3` ไม่ใช่ `3.4` เพราะหารแบบจำนวนเต็มแล้ว **ตัดเศษทิ้งเข้าหา 0** (`-17 / 5` จึงได้ `-3` ไม่ใช่ `-4`) ส่วน `%` ให้ผลที่มีเครื่องหมายตามตัวตั้ง (`-17 % 5` ได้ `-2`) ถ้าต้องการทศนิยมต้องแปลงเป็น `float64` ก่อนหาร

การหาร **จำนวนเต็ม** ด้วยศูนย์จะ panic ตอน runtime (`integer divide by zero`) และถ้าตัวหารเป็นค่าคงที่ `0` จะ compile ไม่ผ่านเลย ส่วน float หารด้วยศูนย์ได้ `+Inf`, `-Inf` หรือ `NaN`
</Aside>

## เปรียบเทียบ

`==`, `!=`, `<`, `<=`, `>`, `>=` ให้ผลเป็น `bool` เสมอ

- เปรียบเทียบได้เฉพาะค่าที่ **type เดียวกัน** — `int(1) == int64(1)` compile ไม่ผ่าน ต้องแปลงก่อน
- string เปรียบเทียบได้ทั้ง `==` และ `<` (เทียบทีละ byte ตามลำดับ)
- slice, map และ function ใช้ `==` ได้กับ `nil` เท่านั้น (ดูบท [Slice](/basics/arrays-and-slices/) และ [Map](/basics/maps/))

## ตรรกะ

| Operator | ความหมาย |
| --- | --- |
| `&&` | AND |
| `\|\|` | OR |
| `!` | NOT |

`&&` และ `||` เป็นแบบ **short-circuit**: ถ้ารู้ผลจากด้านซ้ายแล้วจะไม่ประเมินด้านขวา ใช้ป้องกัน error ได้

```go
// ถ้า user เป็น nil จะไม่ไปเรียก user.IsAdmin() ให้ panic
if user != nil && user.IsAdmin() {
	// ...
}
```

<Aside type="caution">
Go **ไม่แปลงค่าอื่นเป็น bool ให้** `if 1 { }` หรือ `if name { }` compile ไม่ผ่าน ต้องเขียนเงื่อนไขให้ชัด เช่น `if n != 0` หรือ `if name != ""`
</Aside>

## Bitwise และ shift

| Operator | ความหมาย |
| --- | --- |
| `&` | AND |
| `\|` | OR |
| `^` | XOR (และใช้เป็น NOT แบบ unary เช่น `^x`) |
| `&^` | AND NOT (bit clear) — ลบ bit ที่เป็น 1 ใน y ออกจาก x |
| `<<` | shift ซ้าย (`1 << n` = 2 ยกกำลัง n) |
| `>>` | shift ขวา |

`%04b` ใน `Printf` คือพิมพ์เป็นเลขฐานสองให้กว้าง 4 หลัก เติม 0 ด้านหน้า ส่วน `0b1100` คือ literal เลขฐานสอง (ฐานสิบหกใช้ `0x`, ฐานแปดใช้ `0o`) และเขียน `_` คั่นหลักได้ เช่น `1_000_000`

## Assignment และ `++` / `--`

```go
n := 10
n += 5  // n = n + 5
n -= 1  // ใช้ได้กับทุก operator: -=, *=, /=, %=, &=, |=, <<= ...
n++     // n = n + 1
n--
```

<Aside type="caution" title="++ เป็น statement">
ใน Go `n++` ต้องอยู่บรรทัดของมันเอง เขียนแบบภาษา C ไม่ได้:

- `x := n++` → compile error
- `++n` → compile error (ไม่มี prefix)
- `arr[i++] = 1` → compile error

การออกแบบนี้ตัดปัญหา "เพิ่มก่อนหรือเพิ่มหลัง" ออกไปทั้งหมด
</Aside>

## ไม่มี ternary operator

Go ไม่มี `cond ? a : b` ให้เขียนด้วย `if` แทน

```go
status := "offline"
if isOnline {
	status = "online"
}
```

ยาวกว่าเล็กน้อย แต่อ่านง่ายและไม่ถูกเขียนซ้อนจนอ่านไม่ออก

## `min` และ `max`

ตั้งแต่ Go 1.21 มี built-in function `min` และ `max` รับ argument กี่ตัวก็ได้ (อย่างน้อย 1 ตัว) ใช้ได้กับตัวเลขและ string ที่ type เดียวกัน

```go
min(3, 1, 2)          // 1
max(2.5, 7.1)         // 7.1
min("b", "a", "c")    // "a"
```

## Overflow

จำนวนเต็มที่เกินขอบเขตจะ **วนรอบ (wrap around)** โดยไม่มี error หรือ panic ตัวอย่างเช่น `int8` เก็บได้ −128 ถึง 127 เมื่อ `127 + 1` จึงได้ `-128`

<Aside type="tip">
ถ้าข้อมูลมีโอกาสใหญ่มาก (เช่น เงินในหน่วยสตางค์, ID, timestamp) ให้ใช้ `int64` และถ้าต้องการตัวเลขไม่จำกัดขนาดใช้ package `math/big`
</Aside>

## ลำดับความสำคัญ (precedence)

Go มีเพียง 5 ระดับสำหรับ binary operator (จากสูงไปต่ำ)

| ระดับ | Operator |
| --- | --- |
| 5 | `*` `/` `%` `<<` `>>` `&` `&^` |
| 4 | `+` `-` `\|` `^` |
| 3 | `==` `!=` `<` `<=` `>` `>=` |
| 2 | `&&` |
| 1 | `\|\|` |

เมื่อไม่แน่ใจ ใส่วงเล็บให้ชัดเจนไว้ก่อน — `gofmt` จะจัดช่องว่างให้สะท้อนลำดับความสำคัญด้วย เช่น `a*b + c`

## แบบฝึกหัด

1. เขียนโปรแกรมรับจำนวนวินาที (เช่น `3725`) แล้วแปลงเป็น ชั่วโมง นาที วินาที โดยใช้ `/` และ `%` (ผลลัพธ์: 1 ชั่วโมง 2 นาที 5 วินาที)
2. ใช้ operator `&` ตรวจว่าเลขจำนวนเต็มเป็นเลขคี่หรือคู่ โดยไม่ใช้ `%`
3. ทำไม `var a int32 = 5; var b int64 = 10; fmt.Println(a + b)` ถึง compile ไม่ผ่าน และแก้อย่างไร
